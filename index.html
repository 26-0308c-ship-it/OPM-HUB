Adding music to OPM HUB

Artists and admins can share music only after receiving permission from the appropriate rights holders.

  1. Admin signs in using Firebase Authentication.
  2. Enter the song information and select audio and cover files.
  3. Confirm publishing rights and upload.
  4. The song details are saved in Cloud Firestore, and media files are stored in Firebase Storage.

Firebase project setup is required. See README.txt before using the admin panel.
